PathoLens-VLM

A spatially-grounded vision-language model that generates breast cancer pathology reports from whole-slide images and guarantees which slide region each clinical sentence originates from.

Project Description

Existing pathology vision-language models (PathChat, SlideChat, Quilt-LLaVA) produce plausible captions but cannot guarantee which slide region each clinical claim came from. PathoLens-VLM closes this grounding gap by adding a trainable grounding-aware report generation head on top of frozen foundation models.

Problem

Pathology AI reports lack accountability — clinicians cannot verify which tissue area justifies each diagnostic sentence.

Approach

A KL-divergence grounding loss supervises the LLM's text-to-vision attention against BCSS semantic segmentation masks during fine-tuning.

Architecture

CONCHv1.5 patch encoder (frozen) → linear adapter → Llama-3.2-3B + LoRA. Only ~15M parameters trainable; 304M+3B frozen.

Verification

BCSS pointing-game evaluation on held-out test slides yields a 4.4× lift over uniform attention — a measurable grounding signal.

Comparison with Prior Work

Existing pathology VLMs generate fluent captions but provide no per-sentence spatial grounding. MedGround introduces grounded captioning but only for chest X-rays. PathoLens-VLM is the first system to combine all three properties on whole-slide histopathology.

System Architecture

An end-to-end pipeline from whole-slide image to FHIR-formatted pathology report with per-sentence attention heatmaps. Vision tokens are CONCHv1.5 patch embeddings (not TITAN slide tokens) to preserve 1:1 correspondence with patch-level grounding GT.

Inference: WSI → CONCHv1.5 (frozen) → Adapter → Llama+LoRA → grounded pathology report

Sample Output

Deliverables & Demo

Beyond the metrics, the project ships a reproducible code base, a working interactive demo, and full documentation for replication.

01

Trained Model Checkpoint

End-to-end trained PathoLens-VLM checkpoint validated on held-out TCGA-BRCA slides:

  • Adapter + LoRA weights (~60 MB)
  • Loadable via GroundedVLM.from_pretrained()
  • Reproducible via configs/fullscale.yaml
02

Interactive Streamlit Demo

Browser-based demo that lets a user:

  • Pick a precomputed slide
  • Generate a structured pathology report
  • Inspect per-sentence attention heatmaps
  • Download a FHIR DiagnosticReport JSON
03

Evaluation Suite

Five complementary metrics covering quality, grounding, and faithfulness:

  • BLEU-4 / ROUGE-L (caption quality)
  • BCSS pointing-game (spatial grounding)
  • Attention concentration & entropy
  • Faithfulness intervention test
  • Concept recall (tumor/stroma/lymph/necrosis)
04

Reproducible Pipeline

Open-source repository with full automation:

  • Single-command training: make train-grounded
  • Single-command evaluation: make eval
  • 5 ablation configurations (caption / grounding × KL / cosine)
  • 51 passing unit & integration tests
