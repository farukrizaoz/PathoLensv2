A Spatially-Grounded Vision-Language Model for Whole-Slide Breast Cancer Pathology Report Generation

Existing pathology VLMs (PathChat, SlideChat, Quilt-LLaVA) produce plausible captions but cannot guarantee which slide region each clinical sentence comes from. PathoLens-VLM closes the gap by adding a KL-divergence grounding loss that supervises text-to-vision attention against BCSS pixel-level semantic-segmentation masks — yielding measurably better grounding (PG@5 = 4.4× over uniform).

1. Motivation

  • A whole-slide image (WSI) holds ~10⁹ pixels; diagnostic claims hinge on sub-millimetre foci.
  • Modern pathology VLMs generate fluent text but provide no per-sentence spatial grounding.
  • Clinically, a draft report is only actionable if each sentence is traceable to a region.
  • WSI-scale grounded captioning is an open problem — radiology has MedGround (2026); histopathology does not.

2. Data & Supervision

  • TCGA-BRCA — 50 WSIs (35 train / 8 val / 7 test, seed 42).
  • BCSS [Amgad & al., 2019] — pixel-level masks for 4 classes (tumor, stroma, lymph, necrosis), CC0 licence.
  • SlideInstruction — GPT-4 structured captions (reference text).
  • Hybrid GT router: BCSS where ROI coverage ≥ 0.2, CONCH-v1 pseudo-GT elsewhere.

3. Loss Design

ℒtotal = ℒcaption + λg · ℒgrounding + λf · ℒfaithfulness
  • ℒcaption — token-level cross-entropy on the response.
  • ℒgrounding — KL divergence between per-sentence attention and BCSS / pseudo-GT distribution.
  • ℒfaithfulness — Shannon entropy penalty to force concentration.
  • Grounding warmup — first 2 epochs caption-only; λg, λf linearly ramped after.

4. Architecture

Vision tokens are CONCHv1.5 patch embeddings (not TITAN slide tokens), preserving 1-to-1 correspondence with patch-level grounding GT.

7. Discussion

  • Measurable grounding. PG@5 lifts 4.4× over uniform; attention is substantially peakier (entropy 0.938 < 1.0).
  • Slide-specific fidelity. Pointing-game hits concentrate on a single slide (TCGA-AO-A128, 3/12 hits @5); other 6 slides contribute 0 → grounding is non-uniform across slides.
  • Caption quality preserved. BLEU-4 and ROUGE-L match the published smoke-run baseline; adding the grounding loss does not degrade fluency.
  • Reproducibility. 51 / 51 unit + integration tests pass; YAML configs + W&B logs ship in the repo.

8. Future Work

  • Faithfulness intervention test — zero out top-K patches, measure BLEU drop.
  • Concept F1 — per-class recall vs BCSS coverage.
  • Scale from 50 → 151 slides (full BCSS cohort).
  • Layer-sweep validation (attn layers 8, 14, 20).
  • Q-Former adapter ablation.
